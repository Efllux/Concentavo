Concentavo is licensed under GNU AGPL version 3 only (`AGPL-3.0-only`). See LICENSE for the complete terms. This follows Recitavo's open-source direction. Legacy Choirloom storage identifiers remain in place so existing local libraries and backups continue to work.

The unminified application source and build instructions are embedded in each built app and exported practice page. Choose **Guide & shortcuts → App source & licence** to download them. This archive contains the software, not imported scores, library data, personal practice notes or credentials. Third-party dependencies retain their own licences; versions and notices accompany the source. Installers include Electron/Chromium and the official GitHub CLI with their notices.

The app licence does not change ownership or licensing of imported scores, recordings, lyrics or other user content. Publishing a practice website still requires permission to share its musical material.

## Optional commercial services

The app's offline authoring and account-free practice remain in the open-source core. Optional services requiring servers may be offered separately under commercial terms. No paid service or commercial software licence is implemented by this document.

A separate licence for code requires the appropriate rights from its copyright holders. External contributions currently enter under AGPL-3.0-only; a commit sign-off is not permission to relicense someone else's contribution. Before accepting contributions for a dual-licensed edition, establish an explicit contributor agreement identifying the rights holder and obtain acceptance. Recitavo's CLA is a reference, not automatically an agreement for this app.

Architecture and whether a service forms a combined work affect licence obligations; using a separate process or server alone does not establish an exemption. Consult the [GNU licence FAQ](https://www.gnu.org/licenses/gpl-faq.html) and [AGPL text](https://www.gnu.org/licenses/agpl-3.0.html) when designing integrations.
